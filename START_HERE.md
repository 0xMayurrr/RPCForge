# 🚀 START HERE - RPCForge SaaS Landing Page

## ⚡ 3 Commands to Get Started

### Command 1: Install Dependencies
```bash
cd frontend && npm install gsap @gsap/react
```

### Command 2: Start Development Server
```bash
npm run dev
```

### Command 3: Open in Browser
```
http://localhost:5173
```

**That's it! Scroll to see animations.** 🎬

## 🔧 Quick Customization

### Change Animation Speed
Edit `frontend/src/animations/scrollAnimations.js`:
```javascript
duration: 0.5,  // Change this number
```

### Change Colors
Edit `frontend/src/LandingPage.jsx`:
```jsx
className="bg-primary"  // Uses #6467f2
```
